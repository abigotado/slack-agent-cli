# slack-agent-cli v0.2.1

This patch release republishes the v0.2 feature set with the complete immutable
source release bundle. Runtime behavior is unchanged from v0.2.0.

The v0.2 feature set adds a safe operator workflow for creating and connecting
a Slack app without widening the agent-facing Slack API:

- a separately installable `slack-app-provisioning` Skill for Codex and Claude
  Code pins official Slack CLI 4.7.0, its hook dependency, and exact manifests;
- the all-channels manifest grants bot access to public and private channels
  through `channels:*` and `groups:*`, while intentionally excluding DMs,
  group DMs, `chat:write.public`, auto-join, and raw API access;
- interactive profile setup reads one bounded hidden token directly from the
  controlling terminal with signal-safe `auth login --token-tty`;
- Skill installation accepts a closed explicit selector while retaining
  `slack` as the compatible default.

Slack still exposes private channels only after the bot is invited. Runtime
reads and writes remain restricted by exact conversation-ID policies bound to
profile identity and credential generation.

Install with Homebrew:

```sh
brew update
brew upgrade slack-agent-cli
```

Or install from source with Go 1.25.14 or newer:

```sh
go install github.com/abigotado/slack-agent-cli/cmd/slack-agent-cli@v0.2.1
```
