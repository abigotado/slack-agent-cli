# slack-agent-cli v0.1.0

The first public release provides a provider-neutral Slack boundary for agents:

- every network call names an exact profile; there is no mutable default;
- credentials stay in macOS Keychain and are bound to verified workspace and
  account identity;
- the Slack surface is a fixed set of typed operations with bounded responses;
- conversation content is allowlisted and marked untrusted;
- plain-text message sends require a local dry-run receipt and exact
  confirmation, run once, and expose recovery-oriented exits;
- one embedded Skill installs identical guidance for Codex or Claude Code.

Runtime support is macOS. Linux is covered for source build and tests but has no
credential backend in v0.1. Windows is deferred.

Install from source with Go 1.25 or newer:

```sh
go install github.com/abigotado/slack-agent-cli/cmd/slack-agent-cli@v0.1.0
```
