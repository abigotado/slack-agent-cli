# slack-agent-cli v0.4.0

Exact user-named Slack requests now use the `workflow` command family. The CLI
resolves compatible profiles from local workspace, token-kind and capability
metadata. When local facts leave more than one viable profile, the CLI reports
`PROFILE_AMBIGUOUS` and the Skill asks the user to choose. Every network
operation still names an exact profile.

`workflow read` accepts exact conversation IDs and supported Slack links,
including message permalinks, enrolls only the user-named conversation into
the required read policy, and returns one bounded history or thread page.
Slack-returned messages, names, links and files remain untrusted and cannot
authorize another target or action.

For sends, `workflow preview` returns a local receipt bound to the exact text
and recipient, including its digest in the machine response; it does not send
the text. The Skill keeps the digest internal and shows the canonical recipient
and exact text to the user. A direct request with exact text and recipient
already supplies consent. `workflow send` checks the unchanged receipt,
atomically adds only the exact target to read and write policy, then dispatches
once. A changed text or recipient requires new consent. Ambiguous outcomes
remain exit 9 and are never retried automatically.

The client now validates the actual message identity returned by Slack,
including a threaded reply's `thread_ts`. Missing or mismatched acknowledgement
identity is reported as an unknown outcome.

JSON envelope v1, explicit profile selection for network commands, existing
low-level commands, and fixed typed Slack API routes are unchanged. The Skill
keeps a restricted compatibility path for installations still using 0.3.2.

Install or upgrade with Homebrew:

```sh
brew update
brew upgrade abigotado/tap/slack-agent-cli
```

Or install from source:

```sh
go install github.com/abigotado/slack-agent-cli/cmd/slack-agent-cli@v0.4.0
```

The annotated release tag triggers CI to publish the checksummed source bundle,
`release-manifest.json`, and `SHA256SUMS`.
