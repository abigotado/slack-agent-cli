# slack-agent-cli v0.3.2

Thread reads now handle oversized native Slack pages within the existing
100-message transport cap. Every output page contains at most the requested
limit (50 by default), includes the parent only on the first page, and resumes
overflow before advancing Slack's cursor. Follow `meta.next_cursor` until it is
absent; pages may contain fewer messages than the limit. Repeated timestamps
are filtered. Pagination is not a snapshot of concurrent thread changes.

The regression fixture returns all 69 messages as 50 plus 19 without an explicit
`--limit`, with no duplicates. Legacy bound thread cursors remain accepted.
The newest-first native-page fixture returns 50 plus 1 plus 18, also preserving
all 69 messages. Native ranges may move towards older or newer replies; overlap
or a direction reversal is a response error rather than a silently skipped range.
Its recovery hint directs callers to restart once from the first page without
`--cursor`; if it happens again, stop and report it.
History/list bounds and inclusive attachment-proof bounds are unchanged.

`--thread-ts` requires the parent timestamp. Reply timestamps return an
actionable `THREAD_PARENT_REQUIRED` input error at exit 2. Malformed thread
pages and unencodable continuations fail with `SLACK_RESPONSE_INVALID` at exit 1.
The JSON envelope remains v1 with the same schema.

Authentication recovery guidance no longer guesses expiry, revocation, or
clipboard contents from `SLACK_AUTH_REJECTED`. Import credentials through the
operator's hidden terminal input and review policy rebinding after replacement.

Go 1.26.10 or newer is required for the certificate verification security fix.

```sh
brew update
brew upgrade abigotado/tap/slack-agent-cli
```

Or install from source:

```sh
go install github.com/abigotado/slack-agent-cli/cmd/slack-agent-cli@v0.3.2
```

The annotated release tag triggers CI to publish the checksummed source bundle,
`release-manifest.json`, and `SHA256SUMS`.
