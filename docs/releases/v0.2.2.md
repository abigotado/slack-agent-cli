# slack-agent-cli v0.2.2

This patch release fixes profile login with valid Slack bot and user tokens.

Slack's documented successful `auth.test` response represents `user` as a
string. Earlier releases reused the object-valued `users.info` response type,
so a valid token reached Slack successfully but failed local JSON decoding
before the profile could be committed. The runtime now uses a dedicated typed
`auth.test` envelope and includes the official bot response shape in its
regression tests.

Authentication diagnostics also gain a fixed, non-sensitive `error.stage`
field. Existing error codes, messages, and recovery-oriented exit codes remain
unchanged. Token input now applies one bounded printable-ASCII contract to both
hidden controlling-terminal and stdin paths.

Credentials remain stored only in the native macOS Keychain. Tokens are not
written to argv, environment variables, registry files, logs, errors, or
output.

Install or upgrade with Homebrew:

```sh
brew update
brew upgrade slack-agent-cli
```

Or install from source with Go 1.25.14 or newer:

```sh
go install github.com/abigotado/slack-agent-cli/cmd/slack-agent-cli@v0.2.2
```
